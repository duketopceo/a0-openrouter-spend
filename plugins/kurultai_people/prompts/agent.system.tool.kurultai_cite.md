## kurultai_cite
Fetch one citation-sized excerpt when you already know the Kurultai source coordinates.
- `kurultai_cite`: args `source`, `source_id`

example:
~~~json
{
  "thoughts": ["Ground this claim with a single Kurultai citation."],
  "headline": "Citing Kurultai source",
  "tool_name": "kurultai_cite",
  "tool_args": { "source": "notes", "source_id": "ops/deploy.md" }
}
~~~
